# Verification reports

One file per post, written by `/what-is-verify <slug>` and named `<slug>.md`.

Each report records what was checked, against which source, and what the verdict
was — so that six months from now you can tell whether a number in a post was
verified at the time or merely asserted. `/what-is-publish` refuses to publish a
post that has no report here.

See `../what-is-playbook.md` §6 for what a verification pass covers.
