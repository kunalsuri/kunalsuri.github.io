Every developer eventually starts a blog, deletes it, and starts another. This
is that second one.

The plan is simple: write short, honest notes about the things I build and the
decisions behind them — the kind of writing I wish I'd found when I was stuck on
the same problem.

## What you'll find here

- Notes on software and systems I'm working on
- Post-mortems of decisions that went well (and ones that didn't)
- The occasional opinion, clearly labelled as such

## How this site is built

This blog is a static site: Markdown files like this one get compiled to plain
HTML at build time and served straight from GitHub Pages. No server, no
database, no runtime — just fast pages. I'll write up the full stack in the next post.

If you want to follow along, there's an [RSS feed](/rss.xml).
